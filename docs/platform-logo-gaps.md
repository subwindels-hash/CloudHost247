# Platform SVG logos pending review

**260 of 1,091 catalogue entries** still need a sourced, recognisable, code-rendered project logo. This is a work queue, **not** a claim that these projects have no logos. In the UI, “SVG pending” means *our verified SVG rendition* has not been finished. We show neither an invented monogram nor an image element in its place.

An exact filename match can depict a different product (e.g. Yarnpkg instead of Yarn.social, the Phoenix Elixir framework instead of Arize Phoenix, or Cap.so instead of the Cap CAPTCHA). Check the product identity, original artwork and reuse terms before admitting a source. For raster-only originals, compare the generated path trace at tile and detail size; never embed a PNG inside an SVG.

**Known blockers:** Apollo has a first-party GMOD PNG wordmark, but the traces tried so far damage its letters; ZNC's available PNG trace also damages its distinctive letters. Firefly's first-party moth graphic is published for personal use only. [Atomic Server's brand licence](https://github.com/ontola/atomic-server/blob/2a9024008cc25462d40ae4566f99f2d1430e1ebb/brand/LICENSE) reserves commercial use of its marks as selling features, despite the MIT software licence. Canarytokens has a distinctive first-party vector, but its [GPL with special clarifications](platform-logo-licenses/Canarytokens-LICENSE.txt) explicitly discusses integrating covered content into proprietary software; this artwork remains pending rights clarification rather than being copied from Hostinger's gallery. [Plone's mark policy](https://plone.org/foundation/copyright-licensing-logo/policy) calls for an agreement for commercial use; the [WireGuard logo policy](https://www.wireguard.com/trademark-policy/) disallows commercial use absent authorisation, including its use by the WireGuard Easy interface. Budge's repository includes a React boilerplate atom, Auto Ontology's favicon is NVIDIA's parent-company mark, and Apache JSPWiki's site favicon is the generic ASF feather; none is a project-specific substitute. Several compound installers have no single vendor-supplied composite brand. Do not infer trademark permission from an open-source code license. See [the sourcing audit](platform-logo-coverage.md).
