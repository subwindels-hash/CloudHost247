🚀 5-MINUTE DEPLOYMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. UPLOAD
     → Upload cloudhost247-cpanel-df2ef1c.zip to cPanel File Manager
     → Extract and move contents to your app directory (e.g., cloudhost247)

  2. CREATE APP
     → cPanel → Software → Setup Node.js App → Create Application
     → Node.js version: ≥ 20.9.0
     → Application root: cloudhost247
     → Application URL: https://yourdomain.com
     → Startup file: server.js

  3. CONFIGURE ENV
     → Copy .env to your server and customize DATABASE_URL
     → OR use cPanel's Environment Variables UI
     → Set file permissions: chmod 600 .env

  4. INSTALL DEPS
     → In cPanel terminal: cd cloudhost247
     → Run: npm ci --omit=dev

  5. RUN MIGRATIONS
     → CONFIRM_MIGRATION=yes node dist/database/migrate.js up

  6. START
     → In cPanel Application Manager: Click Restart

  7. VERIFY
     → Visit https://yourdomain.com
     → Test: curl https://yourdomain.com/health
