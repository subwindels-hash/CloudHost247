CloudHost247 Node Platform — Ubuntu 24.04 VPS Quick Start
Target: Ubuntu 24.04 LTS VPS (Nginx 1.24 + Node.js 22 LTS + PostgreSQL 16 + systemd)
Full runbook: docs/VPS_DEPLOYMENT.md

1. PROVISION HOST (run once as root on Ubuntu 24.04 LTS)
   git clone <repo-url> /opt/cloudhost247-src
   cd /opt/cloudhost247-src
   sudo bash infrastructure/vps/setup-ubuntu-24.04.sh

2. CREATE POSTGRESQL DATABASE
   sudo -u postgres psql -c "CREATE USER cloudhost247 WITH PASSWORD '<strong-password>';"
   sudo -u postgres psql -c "CREATE DATABASE cloudhost247 OWNER cloudhost247;"

3. CONFIGURE ENVIRONMENT (/opt/cloudhost247/.env, mode 0600)
   sudo cp /opt/cloudhost247-src/cloudhost247-node/.env.example /opt/cloudhost247/.env
   sudo chown cloudhost247:cloudhost247 /opt/cloudhost247/.env
   sudo chmod 600 /opt/cloudhost247/.env
   # Set DATABASE_URL, APP_URL, JWT_SECRET, CREDENTIAL_ENCRYPTION_KEY (PORT=3000 behind Nginx)

4. DEPLOY (build -> migrate -> systemd restart -> healthcheck)
   cd /opt/cloudhost247-src
   # First deploy on a fresh DB (see docs/VPS_DEPLOYMENT.md §6 quarantine gate):
   sudo AUTHORIZED_MIGRATIONS=0041 bash infrastructure/vps/scripts/deploy.sh
   # Subsequent deploys:
   sudo bash infrastructure/vps/scripts/deploy.sh

5. OPTIONAL PRE-BUILT VPS PACKAGE (CI / workstation build)
   cd cloudhost247-node && bash scripts/package-vps.sh
   # Output: cloudhost247-node/release/cloudhost247-vps-<git-sha>.zip

6. TLS & HEALTH VERIFICATION
   sudo certbot certonly --webroot -w /var/www/letsencrypt -d app.cloudhost247.com
   sudo systemctl reload nginx
   sudo bash /opt/cloudhost247-src/infrastructure/vps/scripts/healthcheck.sh

7. OPERATIONS & ROLLBACK
   Logs:     sudo journalctl -u cloudhost247-node -f
             sudo journalctl -u cloudhost247-worker -f
   Rollback: sudo bash /opt/cloudhost247-src/infrastructure/vps/scripts/deploy.sh --rollback
   Backup:   sudo bash /opt/cloudhost247-src/infrastructure/vps/scripts/backup.sh
