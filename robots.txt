# CloudHost247 — static crawl guidance for a PHP/WHMCS deployment.
#
# This file is the FALLBACK. Two better sources exist, in order of preference:
#
#   1. If the CloudHost247 Node platform owns the domain root, it generates /robots.txt
#      dynamically from the live navigation definition and the configured APP_URL, and that
#      generated response takes precedence over this file.
#   2. Otherwise, route robots.txt to `robots.php` with one rewrite rule (see
#      infrastructure/litespeed/webroot-hardening.htaccess), which emits absolute Sitemap URLs
#      built from the deployment's configured SystemURL.
#
# This file cannot do (2) itself, and deliberately does not try: the robots.txt specification
# requires an ABSOLUTE URL in a Sitemap directive, so a relative one is silently ignored by every
# crawler. Publishing "Sitemap: /sitemap.xml" would look correct and do nothing. Sitemap discovery
# still works without it, because /sitemap.xml is linked from the homepage and the sitemap page.
#
# Crawl guidance only — never an authorization mechanism. Private areas are protected by
# authentication, not by this file.
